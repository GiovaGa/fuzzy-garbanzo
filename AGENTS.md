AGENTS
======

This repository is worked on collaboratively by human contributors and automated agents (bots) that add examples, notebooks, or documentation when requested.

Current agent behavior:
- Adds notebooks and small examples on request.
- Creates commits with concise messages when instructed to "Commit".
- Does not push to remotes without explicit user approval.

If you need different behavior (for example, automatic pushes, CI triggers, or stricter commit message styles), please add a short CONTRIBUTING.md or update this file with the desired policies.
